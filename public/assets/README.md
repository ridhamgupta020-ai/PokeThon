# PokeThon Asset Directory Structure

This directory holds static event assets for PokeThon:

- `/public/assets/logo/`: Official event, organizer, and institution SVG/PNG logos
  - `pokethon-logo.svg`
  - `fusion-tech-club.svg`
- `/public/assets/events/`: Event venue, track artwork, and sprint photos
- `/public/assets/partners/`: Verified academic, community, and tech partner marks
- `/public/assets/mascot/`: PokeThon cyber-electric mascot artwork
- `/public/assets/backgrounds/`: Cyber circuit, hex grid, and stage backdrops
